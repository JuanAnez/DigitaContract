# Contract Authentication Service

Este es un servicio de autenticación basado en Spring Security que proporciona endpoints REST para login y logout para el sistema Contract de ClaroPR. Diseñado para ser consumido por un frontend React TypeScript.

## Características

- Autenticación LDAP para usuarios corporativos
- Autenticación de base de datos para usuarios de prueba
- Autenticación en memoria para usuario administrador
- Generación y validación de tokens JWT
- Endpoints REST para login y logout
- Configuración para WebLogic Server

## Endpoints Disponibles

### API Info
- **URL**: `GET /contract/api/info`
- **Response**: Información sobre el servicio y endpoints disponibles

### Login
- **URL**: `POST /contract/api/login-ws`
- **Content-Type**: `application/json`
- **Body**:
```json
{
    "username": "train_ic_user",
    "password": "claro123",
    "appVersion": "1.0.0"
}
```
- **Response**:
```json
{
    "status": 200,
    "message": "OK",
    "data": "eyJhbGciOiJIUzI1NiJ9..."
}
```

### Logout
- **URL**: `POST /contract/api/logout-ws`
- **Content-Type**: `application/json`
- **Body**:
```json
{
    "accessToken": "eyJhbGciOiJIUzI1NiJ9..."
}
```
- **Response**:
```json
{
    "status": 200,
    "message": "OK",
    "data": "Logout successful"
}
```

## Configuración de WebLogic

1. Desplegar el archivo WAR en WebLogic Server
2. Configurar el contexto root como `/contract`
3. Configurar las propiedades de base de datos en el servidor
4. Asegurar que el driver Oracle esté disponible en el classpath

## Integración con React

Este backend está diseñado para ser consumido por un frontend React TypeScript. Los endpoints devuelven JSON y utilizan JWT para autenticación.

### Ejemplo de uso en React:

```typescript
// Login
const login = async (username: string, password: string) => {
  const response = await fetch('/contract/api/login-ws', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ username, password, appVersion: '1.0.0' })
  });
  return response.json();
};

// Logout
const logout = async (token: string) => {
  const response = await fetch('/contract/api/logout-ws', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ accessToken: token })
  });
  return response.json();
};
```

## Notas de Seguridad

- Los tokens JWT expiran en 10 minutos
- Se utiliza encriptación HS256 para los tokens
- Se valida la existencia del token en base de datos
- Se implementan filtros CORS para seguridad
